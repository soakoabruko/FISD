1. В работе нет сложной логики запуска. Достаточно просто открыть server.py и один или несколько client.py в разных терминалах.
2. Команды:
/add <text> — добавить новую задачу;
/list — список задач;
/done <number> — выполнить задачу;
/delete <number> — удалить задачу;
/quit — завершить работу.
3. Для каждого клиента выделяется демон-поток.
4. В работе используется инструмент синхронизации threading.Lock. Он используется при работе с общими ресурсами tasks и task_id_count, когда они изменяются (добавление, выполнение и удаление задачи) или предполагается длительная работа с ними (список задач). В последнем случае создаются snapshot-ы, чтобы освободить их (в случае списка задач это не критично).
