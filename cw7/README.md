Класс NetCom вынесен в отдельный файл netcom.py. Он используется в качестве протокола. Дублирующиеся фрагменты кода удалены.

В метод run() класса ReceiveThread добавлена конструкция try-except для перехвата сетевых исключений (ConnectionResetError и OSError). При потере соединения с сервером испускается сигнал connection_lost. Slot-функция on_connection_lost изменяет статус и выводит сообщение об ошибке.

В классе SendThread добавлены конструкция try-except для перехвата сетевых исключений (BrokenPipeError и OSError) и метод stop(). Он вызывается перед закрытием MainWindow.

Все требования выполнены.

При обнаружении потери соединения slot-функция on_connection_lost изменяет статус.
