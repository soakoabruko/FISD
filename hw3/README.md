Точка входа main.py

В desktop-приложении реализованы возможности ABCDE и F? (pyqtSignal используется для удаления задачи и смены темы оформления. В моем случае использовать pyqtSignal для обновления счетчика задач бесмысленно)

Desktop-приложение имеет следующую архитектуру:

- themes - это директория с темами оформления
- widgets - это директория с виджетами. В контексте PyQt они совмещают логику и представление
- main.py - это точка входа
- task.py - это модель задачи
