Точка входа main.py

В desktop-приложении реализованы все обязательные требования + понравившиеся требования по желанию. Форма для создания задачи открывается в диалоге. Задачи отображаются в окне. Список задач поддерживает фильтрацию по приоритету.

Desktop-приложение состоит из нескольких файлов, где task.py — это модель, а все остальные — это графические элементы. В рамках учебной работы было принято решение совместить логику с отображением и опустить реализацию закрепленных задач.
