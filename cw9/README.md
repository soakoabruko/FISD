Предметная область — это книга рецептов.

Модель данных рецепта включает в себя такие поля, как id, title, category, cook_time в минутах, ingredients и steps. Категории рецептов определены в enum классе RecipeCategory. В поле ingredients хранится список с дата классом Ingredient (name, amount и unit). Единицы измерения ингредиентов определены в enum классе IngredientUnit. В поле steps хранится список с дата классом RecipeStep (desc и image_url).

В проекте реализован весь обязательный функционал. На главной странице через Jinja блок for выводятся все рецепты. На странице деталей рецепта выводятся все его данные. Для добавления и редактирования рецептов используется одна и та же форма за исключением надписей. Это реализовано с помощью Jinja наследования. В шаблоне формы есть небольшой блок JS скриптов. Он необходим для корректного определени ингредиентов и шагов приготовления.

Функционал на выбор включает в себя поиск по названию, фильтрацию по категории, сортировку по новизне и скорости, удаление рецептов и CSS стили (изменение категории реализовано в редактировании рецептов).

Поиск по названию, фильтрация по категории и сортировка по новизне и скорости находятся в GET форме на главной странице. Опции селекторов описаны в кортежах.

На странице деталей рецепта находится кнопка для его удаления. Она использует POST метод (по заданию) и перенаправляет на главную страницу.

CSS стили описаны в /static/style.css. Они применяются к HTML элементам, а не к классам.
